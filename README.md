# 01 - QA API Automation Java

Base de automação de APIs REST com Java, Rest Assured, JUnit 5 e Maven.

## Cobertura
GET, POST, DELETE, path parameters, JSON body, status codes e assertions.

## Executar
```bash
mvn clean test
```

## Estrutura
- `base`: configuração comum
- `endpoints`: rotas
- `tests`: cenários

API pública de demonstração: Fake Store API.
